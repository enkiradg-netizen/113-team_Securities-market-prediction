# Фьючерсы на фондовые индексы CME Group

Основные американские и международные бенчмарки, доступные в линейке CME Group. В таблице сохранены разные размеры контрактов на один индекс. Сортировка ориентировочная: крупные американские индексы обычно наиболее активны, точный объём меняется ежедневно. Источники: [индексы США](https://www.cmegroup.com/markets/equities/us-index.html), [международные индексы](https://www.cmegroup.com/markets/equities/international-indices.html), [E-nano](https://www.cmegroup.com/markets/equities/e-nano-equity-index.html).
