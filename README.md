# Команда 113 - Предсказание стоимости акций

## Описание проекта:
Цель проекта - разработка аналитического сервиса для мониторинга и исследования финансовых инструментов на рынке США, объединяющего сбор, анализ и визуализацию рыночных данных с моделями прогнозирования динамики рынка на различных временных горизонтах.

Сервис позволит пользователю исследовать историческое поведение выбранных финансовых активов, анализировать взаимосвязи между рыночными и макроэкономическими показателями, получать прогнозы и оценивать факторы, оказывающие наибольшее влияние на формирование прогноза. 

Сервис разрабатывается как инструмент аналитической поддержки и самостоятельного исследования рынка, не является инвестиционной рекомендацией.

## Предмет исследования:
Оценка возможности применения классических ML и нейросетевых моделей в прогнозировании направления движения финансовых инструментов.

## В рамках проекта планируется рассмотреть несколько классов моделей:
- Классические статистические и эконометрические модели
- Модели машинного обучения
- Нейросетевые модели
- NLP-модели для обработки новостей и других текстовых источников как дополнительного источника признаков.

## Возможные задачи прогнозирования:
- Определение направления движения актива - рост или падение
- Прогноз доходности инструмента на заданном временном горизонте

*Горизонт прогнозирования будет детализирован после и/или во время работы над Чекпойнтом 2 в ходе подготовки данных.*

## Оценка качества моделей:
- Качество прогноза - способность модели корректно прогнозировать целевое направление актива (long / short) на тестовой выборке
- Интерпретируемость прогноза - способность модели определить факторы, наиболее существенно повлиявшие на прогноз
- Практическая применимость - результативность работы модели на разных финансовых инструментах в режиме backtest

## Данные:
Готовые данные лежат на общем сетевом диске. Качать их из Massive заново не нужно. Логин и пароль выдаёт владелец диска.

**Как скачать.** В `.env` впишите логин (шаблон в `.env.example`), дальше из корня проекта:
```bash
python -m src.data.get_data processed              # склеенные ряды, 142 МБ
python -m src.data.get_data raw/futures/bars       # бары по контрактам, 602 МБ
python -m src.data.get_data raw/futures/trades/CL  # сделки одного фьючерса
python -m src.data.get_data                        # всё, около 45 ГБ
```
Нужна программа `rsync` (Linux: `sudo apt install rsync`, на Mac есть сразу). На Windows подойдёт WinSCP: протокол SFTP, порт 23.

**Что где лежит:**
- `processed/futures_continuous/<код>_<бар>.parquet` — склеенный ряд фьючерса (бары 15min, 1hour, 4hour), ratio back-adjust. Реальная цена = скорректированная цена / `factor`;
- `interim/futures_plan/<код>.csv` — какой контракт был фронтом и следующим в каждый день;
- `raw/futures/bars/<бар>/<код>/<контракт>.csv` — бары по контрактам, как их отдал Massive;
- `raw/futures/trades/<код>/<контракт>/<ГГГГ-ММ>.parquet` — сделки по контрактам, как их отдал Massive;
- `team/` — на диске папка для своих файлов команды.

Список инструментов и причины исключений: `config/instruments.yaml`. Период: 15.11.2021–30.09.2026.

**Что учитывать при работе со сделками и барами Massive:**
- сделки сортируйте по `timestamp`: нумерация `report_sequence` в отдельные дни идёт не по времени (например, 25.02.2026) или повторяется (облигации, 23.10.2024);
- сессия в праздник обычно приписана к следующему торговому дню, поэтому у такого дня сделки начинаются раньше обычного, до 74 часов до его начала. Короткие сессии 09.01.2025, 04.07.2025 и 03.04.2026 идут отдельными днями, хотя в календаре биржи их нет;
- дневным барам Massive (`resolution=1session`) верить нельзя: за часть дней их нет, хотя торги шли (например, BZ 16.02.2022), а у зерновых (ZC, ZS, ZW, ZM, ZL) дневной бар иногда включает ещё и предыдущий день (19.11.2021, 06.07.2022, 28.12.2022, 04.01.2023, 06.07.2023, 27.12.2023, 03.01.2024, 27.12.2024, 03.01.2025). Поэтому объём в плане контрактов — это сумма часовых баров по `session_end_date`, она совпадает с объёмом сделок. Ноль в `next_volume` значит, что у контракта в этот день нет баров;
- в 19 файлах сделок на диске есть по одному лишнему дню бывшего фронта, которого уже нет в плане: даты этих склеек позже уточнены. Дни контракта выбирайте по плану;
- у дальних контрактов встречаются окна со сделками, но без 15-минутного бара: сделки полнее баров;
- время бара в склеенном ряду может повторяться: бар на границе двух торговых дней делится на два с одним `time`. Строку однозначно задаёт пара `time` + `session_end_date`. В 4hour это обычное дело (бар 20:00 UTC у 26 из 34 фьючерсов), в 15min и 1hour единичные случаи: ES и YM 30.01.2025, NG, PA и PL 20.02.2025.

**Как скачать самим через API Massive.** Нужен ключ с подпиской на фьючерсы: `MASSIVE_API_KEY_FUTURES` в `.env`. Запускайте по порядку:
```bash
python -m src.data.contract_plan --product CL NG    # план контрактов
python -m src.data.download_bars --product CL NG    # бары по контрактам
python -m src.data.continuous --product CL NG       # склейка в непрерывный ряд
python -m src.data.download_trades --product CL NG  # сделки, это долго
```
Вместо `--product` можно указать `--member` и имя участника из `config/instruments.yaml`. При временной ошибке Massive скрипты сами повторяют запрос. Если скрипт всё же остановился, запустите ту же команду ещё раз: `download_trades` докачает только недостающие дни.
