# Песочница

Место для экспериментов и черновиков каждого участника: прототипы, ноутбуки, заметки, графики.
В `src/` переносим только то, о чём договорились всей командой.

## Структура

```
sandbox/
├── README.md          ← этот файл
├── Vladislav/
│   ├── README.md      ← оглавление: что лежит в каждой дате
│   └── 26.11.26/      ← материалы за дату
└── <Имя>/             ← папка следующего участника
    ├── README.md
    └── ДД.ММ.ГГ/
```

## Правила

- **Своя папка** — имя латиницей. В чужие папки не пишем.
- **Внутри — папки по датам** в формате `ДД.ММ.ГГ`.
- **В каждой папке даты — README.md:** что сделано, что получилось и как запустить.
- **В оглавление своей папки** (`<Имя>/README.md`) добавляем строку на каждую новую дату.
- **Данные не коммитим:** папка `data/` в git не попадает. Большие файлы (parquet, HTML-графики больше пары мегабайт) тоже не кладём: сохраняем код, который их строит, и картинки PNG.
- Скрипты запускаем **из корня репозитория**, чтобы пути `data/...` работали одинаково у всех.
