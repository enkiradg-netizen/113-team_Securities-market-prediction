## Зачем это всё

Проект состоит из двух частей:

1. **Детектор консолидации** — алгоритм, который находит на графике участки, где цена «застряла» в узком коридоре.
2. **Модель пробоя** — ML/DL-модель, которая предсказывает, куда цена выйдет из коридора: вверх (Long) или вниз (Short).

Модели из части 2 нужна таблица «зона → куда был пробой». Эту таблицу и строит детектор. Поэтому сначала нужен детектор с понятными и проверяемыми правилами.

## Как запустить прототип

Нужны файлы признаков `data/features/...` (папки `data/` в git нет, у каждого она своя; собираются через `python -m src.features.build_volatility --member <участник>`, сейчас посчитаны инструменты Влада).

Из корня репозитория:

```bash
pip install pandas numpy pyarrow plotly
python sandbox/Vladislav/26.11.26/detector_v0/run_box_v0.py --ticker ES --bar 1hour --chart-out es_zones.html
```

Скрипт выведет статистику в консоль, сохранит таблицу зон в `data/detector/futures/ES_1hour/ES_1hour_zones_v0.parquet` и нарисует интерактивный график за последние 60 дней в `es_zones.html`.
